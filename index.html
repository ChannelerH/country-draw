Country Draw

Country Draw is a fast geography drawing game for people who know a map until they try to sketch it. Start with a country name, draw the outline from memory, then compare the result with the real shape.

What to Notice

Block in the overall width and height first. Add one memorable coastline, border, or peninsula only after the main proportion feels right.

Practice Loop

Each attempt turns vague map memory into a visible outline. The page is intentionally lightweight so repeat plays, mobile drawing, and search indexing stay fast.

What is Country Draw?

Country Draw is a browser game where you draw a country, state, flag, or outline from memory and compare your result with a target shape.

Is Country Draw free?

Yes. The game is designed to run in the browser without an account or download.

Can I practice specific countries?

Yes. Country and state pages can launch a specific target so you can practice one shape at a time.
