Practice Loop

Each attempt turns vague map memory into a visible outline. The page is intentionally lightweight so repeat plays, mobile drawing, and search indexing stay fast.

How is this different from Country Draw?

The outline quiz starts with recognition. Country Draw starts with recall and drawing.

Can I switch from quiz to drawing?

Yes. The app links the outline quiz back to the drawing challenge.

Is the quiz timed?

The first version is untimed so the page remains easy to use on desktop and mobile.
