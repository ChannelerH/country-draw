Guess Country By Shape

This outline quiz is made for players who remember coastlines and borders visually. Each silhouette is a direct bridge into country drawing practice.

What to Notice

Compare the silhouette's width, coastline direction, and any narrow peninsula before choosing an answer. Then draw the same shape to strengthen recall.

Practice Loop

Each attempt turns vague map memory into a visible outline. The page is intentionally lightweight so repeat plays, mobile drawing, and search indexing stay fast.

What shapes are included?

The initial quiz uses common country outlines from the drawing pool.

Can I learn from wrong answers?

Yes. Repeating the outline and then drawing it creates a useful memory loop.
